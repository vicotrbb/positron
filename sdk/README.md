# Generated Positron SDKs

The [Rust SDK reference](rust.md) describes the implemented Rust package,
its canonical source, bounded clients, delivery receipts, and release binding.
`rust/` is generated with the native Cargo examples in `positron-api`.
The [TypeScript SDK reference](typescript.md) describes the generated npm package, its bounded client and delivery helpers. `typescript/` is generated by the `generate_typescript_sdk` Cargo example. Shared TypeScript conformance and packaging tests live under `tests/typescript/`.

The [Python SDK reference](python.md) describes the generated dependency-free Python package, typed requests/results, bounded HTTPS, delivery receipts and native wheel release binding. `python/` is generated by `generate_python_sdk`; shared canonical and actual packaging tests live under `tests/python/`.

Package publication and complete SDK Release Set acceptance remain Release Trust operations.
